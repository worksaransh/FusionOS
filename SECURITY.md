# Security Policy

## Supported Versions

We issue security updates for the current major release of **FusionOS**.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The FusionOS maintainers take security seriously. If you discover a potential security vulnerability, please follow our disclosure policy below:

1. **Do NOT open a public issue** on GitHub for security vulnerabilities.
2. Email your findings directly to `security@fusionos.org` or report via [GitHub Private Vulnerability Reporting](https://github.com/worksaransh/FusionOS/security/advisories/new).
3. Include the following details in your report:
   - Description of the vulnerability and its potential impact.
   - Step-by-step instructions to reproduce the issue.
   - Proof-of-concept payload or code snippet (if applicable).
   - Any suggested mitigations.

## Response Timeline

- **Acknowledgement**: Within 48 hours.
- **Initial Assessment**: Within 5 business days.
- **Patch & Advisory Release**: Coordinated disclosure within 30 days of fix validation.

Thank you for helping keep FusionOS secure!
